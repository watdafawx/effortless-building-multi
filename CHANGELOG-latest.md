## 4.2.43

What's new:
- Shape Generator screen redesigned: it adapts to the window (three columns, two, or Library/Settings tabs on narrow screens), so nothing is cut off at any GUI scale.
- Parts list with icons, colored operations and a delete button per part, plus an "+ Add part" button.
- Collapsible settings sections that show how many values changed; toggle buttons for on/off settings.
- Library grouped with shape thumbnails; block rows show the block's icon.
- Bigger preview with block count and size drawn on it, and 3D/Top/Front/Side view buttons.
- Shortcuts: Ctrl+F jumps to search, Ctrl+S (or Enter in the name box) saves a template.
- Radial menu in Shape mode shows the selected shape's name and a turning 3D preview.

Fixes:
- The Block Palette's shape preview uses the palette you are editing.
